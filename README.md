## 🎯 What is SmartAlert?

> **SmartAlert** is a distributed disaster monitoring system that detects **earthquakes**, **floods**, and **gas leaks** using ESP32 + multi-sensor hardware, then **cross-verifies** each event against government APIs (USGS, OpenWeather, OpenAQ) before triggering **SMS, voice call, and email alerts** — reducing false positives by ~70%.

<table>
<tr>
<td width="50%">

### The Problem

Rural areas lack efficient early warning systems. Communication gaps delay rescue efforts and cost lives. Existing solutions are expensive, single-hazard, and centralized.

### Our Solution

An **affordable**, **multi-hazard**, **API-verified** monitoring system with:

- ⚡ **< 5 second** alert delivery
- 🔍 **Triple API verification** before alerting
- 📲 **SMS + Voice Call + Email** simultaneously
- 🖥️ **Government Rescue Center** web dashboard
- 🛑 **False-positive reduction** engine
- 🌐 **Secure remote access** via Cloudflare

## 🏗️ System Architecture

```mermaid
graph TD
    subgraph SENSORS["🔌 Sensor Layer"]
        MPU["MPU6050 — Seismic"]
        MQ["MQ135 — Gas"]
        HC["HC-SR04 — Water"]
    end

    subgraph ESP32["⚙️ ESP32 + FreeRTOS"]
        SM["State Machine<br/>7 states"]
        VERIFY["API Cross-Check"]
    end

    subgraph APIS["🌐 Verification APIs"]
        USGS["USGS Earthquake"]
        OW["OpenWeather"]
        OAQ["OpenAQ"]
    end

    subgraph ALERTS["🚨 Alert Channels"]
        SMS["📱 Twilio SMS"]
        CALL["📞 Voice Call"]
        EMAIL["📧 Gmail SMTP"]
        BUZZ["🔊 Buzzer + LED"]
        WEB["🖥️ Web Dashboard"]
    end

    MPU --> SM
    MQ --> SM
    HC --> SM

    SM --> VERIFY

    USGS --> VERIFY
    OW --> VERIFY
    OAQ --> VERIFY

    VERIFY -->|"✅ Confirmed"| SMS
    VERIFY -->|"✅ Confirmed"| CALL
    VERIFY -->|"✅ Confirmed"| EMAIL
    VERIFY -->|"✅ Confirmed"| BUZZ
    VERIFY -->|"✅ Confirmed"| WEB
    VERIFY -->|"❌ False Positive"| SM
```

<br>

### 🔄 State Machine Flow

```mermaid
stateDiagram-v2
    [*] --> MONITORING
    MONITORING --> EARTHQUAKE_WAIT : Accel > 1.5G
    MONITORING --> WATER_WAIT : Distance < 8cm
    MONITORING --> GAS_WAIT : Gas > 3000
    EARTHQUAKE_WAIT --> EARTHQUAKE_ALERT : API ✅
    EARTHQUAKE_WAIT --> FALSE_POSITIVE : API ❌
    WATER_WAIT --> WATER_ALERT : Rain ✅
    WATER_WAIT --> FALSE_POSITIVE : No rain ❌
    GAS_WAIT --> GAS_ALERT : AQ high ✅
    GAS_WAIT --> FALSE_POSITIVE : AQ normal ❌
    EARTHQUAKE_ALERT --> MONITORING : Reset
    WATER_ALERT --> MONITORING : Reset
    GAS_ALERT --> MONITORING : Reset
    FALSE_POSITIVE --> MONITORING : Auto (3s)
```

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/KedarH28/SmartAlert-Disaster-Monitoring.git
cd SmartAlert-Disaster-Monitoring

# 2. Open main.ino in Arduino IDE

# 3. Install libraries (Arduino Library Manager):
#    → Adafruit MPU6050
#    → Adafruit Unified Sensor
#    → ArduinoJson (v6+)
#    → ESP Mail Client

# 4. Update credentials in main.ino:
#    → WiFi SSID/Password
#    → Twilio SID, Auth Token, Phone Numbers
#    → Gmail App Password
#    → GPS Coordinates

# 5. Board: ESP32 Dev Module → Upload

# 6. Serial Monitor @ 115200 baud → Get IP address

# 7. Open http://<ESP32-IP>/ in browser
```
